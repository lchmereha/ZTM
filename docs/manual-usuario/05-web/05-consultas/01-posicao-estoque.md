# 05/05/01 — Posição de Estoque

## Sobre

Relatório que exibe o saldo atual de produtos em estoque por filial, posição e produto.

<!-- SCREENSHOT: tela-posicao-estoque -->

## Informações Exibidas

| Coluna | Descrição |
|--------|-----------|
| **Filial** | Filial do produto |
| **Produto** | Nome do produto |
| **Código** | Código do produto |
| **Posição** | Posição de estoque |
| **Quantidade** | Quantidade de tags ativas |
| **Lote** | Número do lote |
| **Validade** | Data de validade |

## Filtros

<!-- SCREENSHOT: filtro-posicao-estoque -->

- Filial
- Produto (código ou nome)
- Posição de Estoque
- Lote
- Categoria

> 💡 Use esta tela para verificar rapidamente o saldo de um produto específico antes de realizar movimentações.
