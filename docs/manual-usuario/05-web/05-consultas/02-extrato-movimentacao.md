# 05/05/02 — Extrato de Movimentação

## Sobre

Relatório detalhado do histórico de movimentações realizadas no sistema, incluindo itens e tags envolvidas.

<!-- SCREENSHOT: tela-extrato-movimentacao -->

## Informações Exibidas

| Coluna | Descrição |
|--------|-----------|
| **Data/Hora** | Data e hora da movimentação |
| **Tipo** | Tipo de movimentação |
| **Descrição** | Descrição da movimentação |
| **Situação** | Situação atual |
| **Produto** | Produto movimentado |
| **Tag RFID** | Código da tag envolvida |
| **Ocorrência** | LEITURA, INCLUSAO, ENCONTRADO, NAO_ENCONTRADO |
| **Filial** | Filial de origem |
| **Usuário** | Usuário responsável |
