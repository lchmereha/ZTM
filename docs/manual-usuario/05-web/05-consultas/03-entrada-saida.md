# 05/05/03 — Entrada e Saída

## Sobre

Relatório consolidado de entradas e saídas do estoque por período.

<!-- SCREENSHOT: tela-entrada-saida -->

## Informações Exibidas

| Coluna | Descrição |
|--------|-----------|
| **Produto** | Nome do produto |
| **Código** | Código do produto |
| **Saldo Anterior** | Quantidade antes do período |
| **Entradas** | Quantidade de itens que entraram |
| **Saídas** | Quantidade de itens que saíram (baixa) |
| **Saldo Atual** | Saldo após o período |
| **Filial** | Filial |

## Filtros

<!-- SCREENSHOT: filtro-entrada-saida -->

- Período (data inicial e final)
- Filial
- Produto
- Categoria

> 💡 Utilize este relatório para fechamentos periódicos e conciliação de estoque.
