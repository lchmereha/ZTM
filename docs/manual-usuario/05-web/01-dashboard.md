# 05/01 — Dashboard

## Visão Geral

O dashboard é a tela inicial do sistema, exibindo indicadores-chave do desempenho da filial ativa.

<!-- SCREENSHOT: tela-dashboard -->

## Indicadores (KPIs)

| Indicador | Descrição |
|-----------|-----------|
| **Tags Ativas** | Total de tags RFID em estoque (sem data de baixa) |
| **Produtos** | Quantidade de produtos cadastrados |
| **Movimentações Hoje** | Movimentações criadas no dia atual |
| **Pendentes** | Movimentações em situação diferente de FINALIZADO |

## Gráficos

### Movimentações por Mês

Gráfico de barras mostrando o volume de movimentações nos últimos 6 meses, agrupado por tipo (Impressão, Leitura, Associação, Conferência, Transferência).

### Top Produtos

Tabela com os produtos mais movimentados no período, exibindo:
- Nome do produto
- Código
- Quantidade de movimentações

### Movimentações Recentes

Lista das últimas movimentações criadas, com:
- Descrição
- Tipo
- Situação
- Data de criação

## Seletor de Filial

No topo da página há um seletor para alternar entre filiais. Ao trocar a filial, todos os indicadores e dados são recarregados para a filial selecionada.
