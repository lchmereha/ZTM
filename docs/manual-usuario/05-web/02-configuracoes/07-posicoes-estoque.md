# 05/02/07 — Posições de Estoque

## Sobre

Define as localizações físicas dentro de cada filial onde os produtos são armazenados.

<!-- SCREENSHOT: tela-posicoes-estoque -->

## Campos do Cadastro

| Campo | Obrigatório | Descrição |
|-------|-------------|-----------|
| **Filial** | Sim | Filial à qual a posição pertence |
| **Nome** | Sim | Nome/identificação da posição |
| **Ativo** | Sim | Se a posição está disponível |

## Como Cadastrar

1. ✏️ Clique em **"Novo"**
2. ✏️ Selecione a **Filial**
3. ✏️ Informe o **Nome** da posição (ex: "Prateleira A1", "Doca 3", "Sala 101")
4. ✏️ Marque como **Ativo**
5. ✏️ Clique em **"Salvar"**

> 💡 Use nomes intuitivos que reflitam a localização física real no galpão.

## Como Usar

As posições de estoque são utilizadas para:
- Vincular tags RFID a uma localização específica
- Facilitar a localização física de produtos
- Gerar relatórios de ocupação por posição
